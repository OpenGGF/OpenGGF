# TALON reel portraits

Original GPT Image native-pose transformation, reduced to the native 32×32 cell.
See `provenance.json` and `prompts.json`; raw attempts/native references stay in
`$HOME/scratch/agent-tmp/mt-reels-title-20261110/`. No decoded ROM art is packaged.

Normal uses the approved character palette. Powered uses the same authored head geometry with the existing Solar palette (a deliberate palette alias, not a new drawing).
There is no animation within a symbol; the native reel supplies scrolling/timing.
The head scale follows native portraits, not gameplay body bounds. Head-only art
has no torso; review guide boxes mark the head/baseline only.

S2 replaces symbol 0 for the selected main and symbol 1 for the first sidekick.
TALON solo owns both lead and Tails symbols. S3K uses 1/2 and powered symbol 7;
Knuckles, Eggman, Ring, BAR and jackpot are native. Missing slots fall back.
The local 16-colour palettes do not overwrite native level palettes. Native
white-entry fades modulate the portraits; native backing fills transparent pixels.

Title mascot art is **not delivered** by this lane. See the title ownership
research in the original-character design's Coverage audit section. No title
capture or title animation certification is claimed.
