#   card-id: layer; layer; ...        layers are drawn back to front

#   hero sonic|tails|knuckles FRAME   a character mapping frame (hex), or anim=ID to animate

#   icon NAME                         a text-art icon from icons.txt
#   fx speed|burst|sparkle|stars|rings|fire|water|zap
#
# Then optionally: X,Y offset from the art window's centre (large-card pixels, 76x42 window),
# flip, xSCALE (x2, x0.5) and aALPHA (a0.5). Small cards draw the same picture at half size.
