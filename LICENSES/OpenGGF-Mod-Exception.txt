1. Definitions

"OpenGGF" means the program that this exception accompanies, and any version
of it that keeps this exception.

"Mod API" means the classes and interfaces of OpenGGF that are marked with the
annotation com.openggf.game.ModApi, the public classes of the OpenGGF mod SDK
and mod test kit, and the documented mod manifest and resource formats.

"Mod Interface" means the Mod API together with any other classes,
interfaces and members of OpenGGF that a mod calls, implements, extends or
overrides. The Mod API marks the part that carries a compatibility promise;
using other parts does not stop a work from being a Mod.

"Mod" means a work that is loaded, or is intended to be loaded, by OpenGGF's
mod loader and that uses OpenGGF only through the Mod Interface. Apart from what
compiling against the Mod Interface necessarily incorporates (such as type,
member and annotation references and constant values), a Mod may include
material taken from OpenGGF only where that material is licensed to you under
other terms that allow it, such as the MIT-0 mod starter material or the MIT
example mods. A work that otherwise copies or adapts OpenGGF code is not a Mod,
and packaging, renaming or loading copied or modified OpenGGF code as a mod
does not make it one.
