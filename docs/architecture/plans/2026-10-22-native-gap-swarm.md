1. Each worker reproduces its actual failure, implements the native behavior,
   runs focused meaningful regressions and applicable guards, then provides a
   local commit, exact command, source state, failures/skips and remaining limits.
   Retain queued jobs; do not launch duplicate unchanged selections.
2. The lead reviews and composes committed milestones in this isolated tree.
   Later edits require affected checks. Source-correct isolated changes that
   expose compensation remain explicit until the combined path is repaired.
3. Inspect `run_categories.py --base 94c40570a15a11b70caf7456e9b0d0a8eec8a9b4`
   on the final composition. State candidate count, expected cost and stopping
   rule; run actual Java 25/Lua 5.4/PowerShell preflight, then one combined
   change-based smoke selection and affected native/domain checks. Shared
   changes use the complete selected smoke categories; no manual narrowing.
4. Attribute disputed failures with bounded matched tests on base and current
   state. The peer's historical 14 ordinary and four guard failures are neither
   a current baseline nor waived regressions. New or worsened failures block
   integration; unchanged attributed baseline failures do not.
5. Rendering uses surfaceless EGL with display variables unset and known
   no-device audio. Native trace/audio evidence requires exact ROM, movie,
   producer, service boundary and completed coverage. Comparison rows never
   supply gameplay state. The dedicated timing contract remains the only
   restricted readiness/input-admission exception.
6. Coordinate the destination window with the peer, fetch/fast-forward its
   current branch without switching it, reconcile upstream intent, complete
   required affected post-integration checks, and push only that destination.
   Keep incomplete scopes open; do not describe focused or partial evidence as
   a full-suite, complete-game or all-route pass.
7. Inspect and acknowledge category diagnostics after reading their summaries.
   Preserve compact decisions and rejected-approach evidence in existing task
   artifacts; remove consumed raw diagnostics. After successful verification
   and push, account for every owned change before removing fully merged
   worktrees/branches. Preserve unknown and unmerged work.
