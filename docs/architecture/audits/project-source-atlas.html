What travels through time

Each stop is an exact first-parent Git snapshot, sampled at daily integration boundaries. Paths are identities: moves appear as an old path and a new path. File presence changes; circle layout and sizes use current or last-known metadata so positions stay stable. Named declarations, imports and line counts are not reconstructed at every past date. Removed paths retain metadata from their final version before deletion.

Select a region to zoom. Select empty space to step back. Every smallest circle is one Java source file.
