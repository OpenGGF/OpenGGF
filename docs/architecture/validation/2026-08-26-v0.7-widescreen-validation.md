## Validated contract

The implementation preserves 320x224 as the exact native behavior and the sole
trace-comparison authority. The supported presentation widths are 352x224 and
400x224, with 400x224 as the primary widescreen target. The 528x224 preset is a
best-effort smoke tier, and 800x224 remains exploratory.

Wider presentation changes viewport layout and capture readback only. It does
not widen ROM world boundaries, hydrate gameplay from trace data, select a
different trace path, or alter native replay timing.
