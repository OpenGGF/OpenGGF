# Object property schema coverage

Generated by `com.openggf.tools.editor.ObjectPropertyCoverageTool` from per-game providers.
Every numeric ID is listed, including reserved/unimplemented IDs. A schema describes
subtype bits; it does not certify that a stock object supports authored playtests.
S3K entries cover common IDs in both S3KL and SKL. Family-dependent IDs and keyed objects use raw fallback.
Named fields retain unknown bits and values byte-for-byte. Unused subtype fields explicitly identify objects that ignore the byte.
Numeric frames, counts and trigger indices describe ROM inputs, not a guarantee that every byte selects valid art or a safe route.
