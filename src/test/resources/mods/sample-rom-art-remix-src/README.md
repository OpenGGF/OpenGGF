# ROM Art Remix sample

This maintained source project demonstrates bounded Sonic 2 ROM-art intake without
shipping any Sega-owned art. Build OpenGGF first, then run `build.ps1` or `build.sh`
with the engine JAR, SDK JAR, and a fresh output directory.

The sample uses the default Sonic team. Its one display object renders two Tails
flight mapping frames materialized in memory from the user's supplied Sonic 2 ROM.
