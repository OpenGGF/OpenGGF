# sample-platformer

A standalone (no-ROM) OpenGGF mod: one TMX-authored act, an original character ("Bolt")
with a distinct `PhysicsProfile` and a double jump, a patrolling badnik ("ZapBug"), a spring
gimmick ("SpringPad"), looping OGG music, and WAV sound effects.

`pom.xml` wires every content-conversion step into Maven's `generate-resources` phase via
`exec-maven-plugin` (playable/object art, the TMX level with its namespaced `--music` track)
and packages/validates the built jar in `prepare-package`, so a plain `mvn package` produces
`target/sample-platformer-mod.jar` end to end. Source assets under `src/main/mod/` (the TMX
level, GPAL palette, and four PNG/YAML art sheets) and `src/main/resources/audio/` (the
audio manifest plus OGG/WAV assets) are checked in pre-generated by
`SamplePlatformerAssetGenerator` — see that class's Javadoc for the one non-hermetic step
(the OGG encode).
