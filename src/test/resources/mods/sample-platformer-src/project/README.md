# sample-platformer

A standalone (no-ROM) OpenGGF mod: one TMX-authored act, an original character ("Bolt")
with a distinct `PhysicsProfile` and a double jump, a patrolling badnik ("ZapBug"), a spring
gimmick ("SpringPad"), looping OGG music, and WAV sound effects.

See the repository root [`README.md`](../README.md) for build instructions and
[`docs/modding/guides/standalone-platformer.md`](../../../../../docs/modding/guides/standalone-platformer.md)
for the full build-along guide.
